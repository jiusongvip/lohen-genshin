2. Audit Categories

2.1 Technical SEO

Score: 75/100

What Works

  • robots.txt correct and references sitemap
  • XML sitemap-index + sitemap-0 well-formed
  • 404 page has noindex, follow and clear H1
  • Canonical tag present on homepage
  • Zero third-party scripts (self-hosted assets only)

Findings

Canonical vs sitemap homepage URL mismatch Medium

Canonical is https://www.lohen-genshin.com (no slash) but sitemap lists https://www.lohen-genshin.com/ (with slash, trailingSlash:'always'). Two URL forms for the homepage create indexation ambiguity.

Recommendation: Pick one form (no-slash per framework spec), keep sitemap and canonical identical, and add a 301 between the two forms.

404 page emits full rich structured data High

404.html includes WebPage, VideoGame, Organization, BreadcrumbList, HowTo, and Game JSON-LD. Error pages should carry no structured data.

Recommendation: Strip all JSON-LD from the 404 template; keep only noindex meta and the link back to /.

IndexNow key file exists but not wired Medium

4e1f2c3d4a5b6789f0a1.txt exists at root but there is no <link rel='indexnow'> and no submission pipeline to api.indexnow.org. The file alone does nothing.

Recommendation: Wire IndexNow submission (Cloudflare Pages IndexNow integration or a worker) before/at launch.

No security headers verifiable pre-deploy Low

No live origin to inspect. CSP, HSTS, X-Content-Type-Options, Referrer-Policy cannot be confirmed.

Recommendation: Add security headers via Cloudflare Pages _headers at deployment; enable HSTS.

Findings

Fabricated Game + AggregateRating structured data Critical

Game entity with aggregateRating 9.4/10 and ratingCount 78, plus a review authored by the site's own editorial team. No user voting system exists on the page. This violates Google's review-snippet guidelines (self-serving/fake reviews) and risks a manual action.

Recommendation: Delete the Game+AggregateRating JSON-LD block immediately. If a rating is wanted, implement a real user voting widget and mark up only live aggregate data.

404 page schema pollution High

404.html emits VideoGame/Organization/BreadcrumbList/HowTo/Game JSON-LD. Error pages must not carry rich entities.

Recommendation: Strip all JSON-LD from the 404 template.

Duplicate FAQ question in FAQPage Low

Same Knights of Favonius question twice in mainEntity.

Recommendation: Deduplicate the FAQ array.

Author identity inconsistent Low

Schema author Organization 'Editorial Team' vs visible text 'active player'.
